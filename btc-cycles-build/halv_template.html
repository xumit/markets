Each period from one halving to the next, rebased to 1.00 on the close at the start halving. Log scale. Prices in USD. Data through /*ASOFDATE*/.

Each line is one halving-to-halving period. Click a cycle name to hide or show its line. H-H Cycle 4 is still running, so it is shown but kept out of the average.
